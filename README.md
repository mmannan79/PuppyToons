# PuppyToons — AI Video Production Playbook

A repeatable production system for PuppyToons: warm, funny, family-friendly 3D animated puppy adventures and interactive early-learning quizzes starring Azula, a tiny Golden Retriever.

This playbook combines two workflow ideas:
- **Character-led story production:** stable character references, beat-by-beat keyframes, short animation clips, fixed voice anchors, continuity checks and timeline assembly.
- **Interactive kids quizzes:** a clear question, multiple choices, a real thinking pause, answer reveal, encouraging feedback and a simple learning takeaway.

## Our format

**Main series:** *Azula’s Little Learning Quiz!*

- Audience: preschool and early-primary children, roughly ages 3–8.
- Default language: simple, natural English. Optional localized editions should be created as separate versions, not mixed-language episodes.
- Video: 16:9 landscape, 1920×1080 export where available.
- Episode: exactly 5 questions; target finished runtime **6–8 minutes**.
- Style: polished, expressive 3D family-film animation; bright but not visually overwhelming.
- Host: Azula, a tiny fluffy golden-brown Golden Retriever puppy with floppy ears, expressive brown eyes, black nose and a teal-blue collar.
- Format: five mini-adventures rather than five rapid-fire cards. Each question has a setup, choices, thinking time, reveal, explanation and celebratory payoff.

> The 6–8 minute target is achieved through story context, repeat-the-question moments, 8–12 seconds of thinking time, answer explanations, Azula reactions, transitions and a short intro/outro—not by padding or rushing narration. Always time the assembled edit.

## Production principles

1. Keep Azula's appearance, collar, size and personality consistent.
2. Use reference sheets and create one clear keyframe per shot.
3. Give each shot one main action and one readable camera instruction.
4. Keep spoken lines short and understandable; use one consistent voice anchor.
5. Separate narration and sound effects from generated footage when possible so timing can be edited precisely.
6. Every quiz question must allow children time to answer before the reveal.
7. Verify every answer and explanation before production.
8. Review the final video as a parent and educator would; AI prompts reduce errors but cannot guarantee perfect outputs.
9. Do not promise virality or use manipulative pressure. Prioritize learning, warmth and accessibility.
10. If the content is directed to children, correctly set YouTube's audience designation and follow current platform requirements.
