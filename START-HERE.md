# Start Here: Make a PuppyToons Quiz Episode

## 1. Pick one category
Examples: animals and pets, colors and shapes, fruits and vegetables, counting, weather and space, or everyday science. Keep all five questions within one category.

## 2. Lock the episode plan
Create exactly five distinct questions for ages 3–8. Each must have one unambiguous correct answer, three plausible but child-safe distractors, one short explanation and one playful Azula reaction. Avoid questions that depend on cultural assumptions or disputed facts.

## 3. Plan for 6–8 minutes
Use the timeline in [the five-question template](production/five-question-video-template.md). Five questions are not five 10-second clips: each question is a small learning adventure with a setup, choices, thinking pause, answer reveal and payoff.

## 4. Create assets
1. Generate or select the approved Azula character reference.
2. Create a reusable 16:9 quiz-card design and simple environments.
3. Generate a keyframe for each planned shot, using the same character references.
4. Animate each keyframe with one clear action and minimal camera movement.
5. Keep on-screen text short. Add final typography in the editor if the video model renders text unreliably.

## 5. Record/generate audio separately where possible
Use one consistent, cheerful narrator voice. Keep Azula's character voice distinct only if it improves clarity. Do not clone a real person's voice without permission. Music should sit well below narration.

## 6. Edit and time
Assemble in story order. Leave 8–12 seconds for the child to think on each question, with a gentle visual cue (countdown dots, a soft ticking rhythm, or Azula waiting). Do not reveal the answer early in audio, subtitles or visuals. Check the actual runtime; target 6:00–8:00.

## 7. Quality check before publishing
Use [the child-friendly checklist](quality-control/child-friendly-checklist.md) and [upload checklist](youtube/upload-checklist.md). Watch the whole export with sound on. Check every answer, subtitle, voice line, visual continuity issue and transition.

## Suggested first episode
Use [Episode 001: Animal Quiz](episodes/episode-001-animal-quiz.md) as the starting example. Customize it and verify the facts before generating assets.
