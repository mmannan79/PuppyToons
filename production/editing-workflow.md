# Editing and Assembly Workflow

## 1. Organize assets

Use one folder per episode:
- `script/` — approved script, answer key and fact-check sources.
- `references/` — approved Azula reference and any recurring environment sheets.
- `keyframes/` — numbered opening frames.
- `clips/` — numbered generated shots.
- `audio/` — narration, music and sound effects with license notes.
- `export/` — final export and review notes.

Use consistent filenames such as `Q01_01_setup`, `Q01_02_choices`, `Q01_03_think`, `Q01_04_reveal`.

## 2. Generate in story order

1. Finalize the script and shot list before spending generation credits.
2. Create the character reference sheet(s).
3. For each shot, generate the keyframe and then animate that keyframe before moving to the next shot.
4. Keep the approved reference attached/selected when the tool supports it.
5. Do not assume the newest asset is the correct one. Match each output to its shot ID and review its starting frame.
6. If a generation fails, retry only the failed asset. Avoid regenerating completed work unnecessarily.

## 3. Edit the timeline

1. Set a 16:9, 1920×1080 project when supported.
2. Place clips in shot-list order.
3. Add narration as a separate track where possible.
4. Align question text, options, answer highlight and narration to the same reveal point.
5. Add a real thinking gap of 8–12 seconds per question. If the animation is shorter, extend a stable quiz-card shot or loop subtle background motion; do not stretch dialogue unnaturally.
6. Add subtitles/captions where helpful and verify spelling manually.
7. Keep transitions simple and consistent.
8. Add recap and outro, then check the total runtime.

## 4. Runtime check

- Under 6:00: add useful context, a second clue, or a meaningful answer explanation; do not pad with repeated filler.
- 6:00–8:00: target met if all five questions and pauses remain understandable.
- Over 8:00: trim redundant setup, overly long transitions or repeated narration; do not remove the thinking time entirely.

## 5. Final review

Watch the whole video from beginning to end with sound on. Check the first frame of every clip, character identity, answer timing, voice clarity, subtitles, music balance, and any accidental flashes or sudden changes. Verify the final export actually opens and plays.
